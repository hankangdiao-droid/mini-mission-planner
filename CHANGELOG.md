# Changelog

## 0.1.0 — Technical preview

- Browser-only survey, facade and orbit planning for provisional Mini 4 Pro / Mini 5 Pro profiles.
- WPML KMZ export, mission splitting, project / GeoJSON import and restricted native KMZ import.
- Chinese / English interface, light / dark themes, Beijing initial view and optional synthetic demos.
- Online OpenStreetMap basemap by default, offline grid and configurable XYZ tiles.
- Submit-only place search using a user-configured Nominatim-compatible provider. No default geocoding endpoint, autocomplete or automatic retries. Configurable result attribution and link.
- Source and static distribution include project and runtime dependency license notices.

Both aircraft profiles in this independent tool still require native-task comparison and flight verification. This release does not validate terrain, collision, airspace permission or actual DJI Fly trajectories.
