核心测试包含两款机型、三种模式、间距、自交、坐标范围、尖锐折返、稠密请求上限、相对高度提示、分段锚点与照片唯一性、KMZ 字段回读、XML 转义、非法文件、受限动作导入和底图模板校验。

浏览器测试包含主题与语言切换、主题记忆、机型和规划模式、导出确认门槛、实际下载 ZIP/KMZ 检查、窄屏输入与横向溢出、失败底图提示和自定义瓦片加载状态。测试拦截外部地图请求，自定义瓦片用微型 PNG 夹具模拟，不通过自动平移访问公共地图服务。

单独通过 HTTP 请求确认当时 OpenStreetMap 的一张测试瓦片可返回 200。这不能保证浏览器、其他地区或之后的地图请求都可用。

UI detector 曾提示两处侧边强调线、字体及网格背景。已移除强调线及 Inter，保留用于地图编辑的网格。它是编辑辅助，不是装饰，也不代表真实地图坐标线。

未验证项：DJI Fly 任务实际解析、RC 2 文件存储权限、两款机型真机动作和轨迹。默认枚举与失联动作仍需版本化验证。文件模式扫描不等于全面秘密审计。
