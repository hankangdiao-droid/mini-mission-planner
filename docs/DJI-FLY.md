# 将任务传到 DJI Fly / RC 2

DJI 官方指南说明 DJI Fly 不提供一般 KML 航线导入。本工具输出 WPML KMZ，采用**替换已有占位任务文件**的方法。属于手动文件工作流，不是官方导入接口，存储位置及行为可能随版本变化。

1. 在 DJI Fly 内新建含 2 个航点的短任务并保存。记录其名称，不要选择重要任务作为占位。
2. USB 连接遥控器和电脑。若系统允许文件访问，检查 `Android/data/dji.go.v5/files/waypoint/` 下的任务目录。
3. 备份对应占位目录及原生 `.kmz`。不同固件存储和权限策略可能不同，找不到时先停止替换并记录版本。
4. 将原生 KMZ 复制到电脑。点击本工具“导入原生 KMZ 校准枚举”，只提取命名空间和机型配置。
5. 导出短规划，确保本机飞机型号正确。将新 KMZ 改为占位任务原有的完整文件名，替换对应文件。不要整体清空任务目录。
6. 退出再打开 DJI Fly，打开占位任务，核对航点数、经纬度、高度、机头、云台、拍照动作、速度、任务结束及失联设置。
7. 若任务打不开、解析后缺少动作或高度发生变化，恢复原备份并提交脱敏兼容性反馈，不应直接飞行验证解析错误。
8. 先在允许飞行且无障碍的场地验证短任务。按分段任务逐份创建占位和替换，每份单独核验、起飞。

## 检查表

- [ ] 实际起飞点与计划起飞点相符，所有高度相对该点。
- [ ] 地图坐标和现场位置没有偏移。
- [ ] 爬升、转弯和返航路径有净空。
- [ ] 当前固件正确显示逐点速度、机头及云台角度。
- [ ] 拍照动作和不拍照锚点符合预期。
- [ ] 电池、风速、定位和现场许可适合该任务。
- [ ] 有人工接管与终止条件。

当前工具不能替代上述现场检查，也不能验证 RC 2 文件权限或飞机实际行为。
