# 地名搜索与地图跳转

地名搜索默认关闭，不内置共享公共查询地址。地图浏览、经纬度定位和航线规划不依赖地名搜索。

## 配置与使用

1. 点击地图上方“配置搜索”，或打开“底图与定位”。
2. 填写有权使用的 Nominatim 兼容查询地址，支持 HTTPS 或本机 HTTP。浏览器直连需要服务允许当前站点的 CORS。
3. 按服务要求填写“搜索结果版权归属”及可选版权链接。例如 OSM 数据通常标注 © OpenStreetMap contributors，版权链接为 https://www.openstreetmap.org/copyright 。结果下方显示文字和链接，需要标志或额外声明的服务，应由部署者先完善相应展示。
4. 点击“应用查询服务”，输入中文或英文地名，按回车或点击“搜索”，选择候选结果即可跳转。例如 New York, USA。同名地点可补充国家或州。
5. 点击“关闭搜索”停用服务。配置仅保留在当前页面，刷新后清除，不导出到项目文件或 GitHub。

返回格式须兼容 [Nominatim Search API](https://nominatim.org/release-docs/latest/api/Search/) 的 jsonv2，包括字符串 lat、lon 和 display_name。可选 boundingbox 与 address 用于地图缩放和候选描述。并非所有地图平台的原生搜索 API 都直接兼容，必要时使用自己的适配代理。

跳转按有效边界框缩放，否则定位中心。不会修改绘制点、航点、起飞点或导出参数。无结果、取消、超时和错误不会改动航线。规划器支持纬度 ±80°，搜索采用同样限制。

## 密钥与隐私

搜索词和浏览器网络信息会发送给配置的服务，请勿输入私人或保密信息。结果在当前页面最多缓存 100 个查询，刷新后清除。同源标签页共享的本地记录仅为请求时间戳，不含搜索词或服务地址。

若服务允许浏览器公开使用的密钥，可按其要求在查询地址中配置参数，并在提供商后台限制来源与额度。浏览器配置无法保密，不要填写服务器私密密钥。需要私密密钥、签名或服务器请求的服务，应由自己的后端代理管理，前端只填写代理地址。不得将带密钥的地址、页面截图或日志提交公开仓库。

## 服务政策与公开部署

本工具仅在用户提交时请求，不自动补全、不轮询、不自动重试。请求间隔至少 1.1 秒，并缓存本页结果。支持 Web Locks 的浏览器会串行处理同源标签页查询。这是客户端节流，不能限制不同电脑的合计流量，也不能满足所有提供商的限额要求。

用户自行填写地址仍须遵守服务条款。特别是 [Nominatim 公共服务政策](https://operations.osmfoundation.org/policies/nominatim/) 限制整个应用所有用户合计每秒最多一次请求，禁止自动补全与系统性批量查询，要求正确归属和可识别应用。该政策对 AI 生成的接入也有明确要求，应用开发者须了解政策并承担责任。不要把自行配置视为规避限制的方法。

面向多人部署时，由部署者选择允许该用途的服务，或配置统一限流、缓存、归属及应用标识的代理或自建服务。公开源码不表示第三方服务授予免费无限使用权限。地图定位和搜索不认证航线合法性或净空。
