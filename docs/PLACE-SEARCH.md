# 地名搜索与地图跳转

地图上方输入城市或地点名，按回车或点击“搜索”，从候选列表选中地点后跳转。可输入中文或英文，并添加国家或州以区分同名地点，例如 `New York, USA`。结果语言跟随界面，识别效果依赖查询服务和 OSM 数据。

跳转按返回的边界框缩放，无可用边界框时定位到中心坐标。跳转不修改绘制点、航点、起飞点或导出参数。搜索取消、超时和没有结果都不会改动航线。

## 默认服务与使用政策

当前本地预览使用 Nominatim 公共查询服务。用户应阅读并遵守 [Nominatim 公共服务政策](https://operations.osmfoundation.org/policies/nominatim/)。该服务限制**整个应用合计每秒最多一次请求**，禁止自动补全和系统性批量查询，要求归属说明与有效 Referer/User-Agent。服务容量有限，访问可能受限。

本工具仅在用户提交搜索时发起请求，不在输入时查询，不后台轮询，不自动重试。请求间隔至少 1.1 秒，本页最多缓存 100 个查询。浏览器支持 Web Locks 时串行处理同源标签页的请求，并利用本地时间戳约束间隔。默认保留浏览器 Referer，不伪造 HTTP 标识。

本机标签页间节流不能约束不同电脑的总流量。因此，此默认配置用于当前的本地预览。公开多人部署前，需要开发者配置满足整体限流、缓存与可识别应用要求的代理、自建服务或合适的第三方服务，并承担使用政策合规责任。不同服务须遵守各自条款。

“底图与定位”中可以直接更换 Nominatim 兼容查询地址，无需改代码。允许 HTTPS 或本机 HTTP，浏览器直连服务需要允许当前来源的 CORS。默认协议说明见 [Nominatim Search API](https://nominatim.org/release-docs/latest/api/Search/)。

## 隐私与边界

搜索文本会发送给所选查询服务，请勿查询含有私人或保密信息的内容。结果在本页缓存，刷新后清除。跨标签页使用的本地记录只有请求时间戳，不保存搜索文本。自定义查询地址不会写入项目文件或 GitHub。

当前规划器支持纬度 ±80°，搜索结果也采用同一坐标限制。跨日期变更线或无效的边界框会降为中心点定位。返回地点仅用于查找地图位置，不认证航线合法性或净空。
