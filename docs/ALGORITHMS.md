# 算法与高度口径

## 坐标

输入为 WGS84 经纬度。以首点建立局部等距近似：`x = R cos(lat0) (lng-lng0)`，`y = R (lat-lat0)`，角度转换为弧度，`R = 6371008.8 m`。工具限制几何顶点在首点 2 km 内，纬度 ±80°，拒绝跨日期变更线的路径。适合小范围规划，不替代精密测量投影。

## 相机间距

厂家给出的 FOV 未在本工具来源中明确标为水平视场角。这里**假设为对角线视场角**并结合 4:3 格式推算：

```text
diagonal = 2 × distance × tan(FOV / 2)
width = diagonal × 4 / 5
height = diagonal × 3 / 5
alongSpacing = width × (1 - alongOverlap)
acrossSpacing = height × (1 - acrossOverlap)
```

Mini 4 Pro 使用 82.1°，Mini 5 Pro 使用 84°。这是假设模型，需要现场照片验证。区域测绘以俯拍高度估算足迹，立面以离墙距离估算足迹。数字裁切、畸变校正、不同照片比例、斜拍和遮挡均会影响结果。

## 区域测绘

将多边形旋转至扫描坐标系，按跨线间距放置扫描线。采用半开区间相交规则，排序交点并成对截取内部区间，所以支持无孔洞的简单凹多边形。逐条交替往返并按沿线间距加密。连接不同区间的直线可能穿过区域外部，不作避障。

## 立面与环绕

立面开放折线按绘制方向左/右偏移，拐角使用法线角平分线的交点。尖锐折返和偏移后自交被拒绝。每层沿偏移折线采样，机头朝最近的原始折线点，云台水平。不同高度层按相机足迹推算间距，交替方向。

离墙距离是二维设计值，在拐角和现场建筑轮廓误差下不构成净空保证。当前独立工具未移植裂察者的 BVH 网格检测。

环绕从中心北侧开始，按圆周长度 / (速度 × 点间时间) 划分圆周，机头朝向中心，保留闭合终点。点间时间用于采样，并非严格时间触发拍摄协议。

## 分段和时长

每份最多 N 个点，默认 N=99。后续任务加入上一份末点作为 `photo=false` 的交界锚点，避免分段处丢失连线或重复拍照。所有航点按每份从 0 重编号，各任务是独立架次。

路线距离按局部二维距离与高度差的三维直线计算。估算时间为各段距离 / 终点速度，加上照片数 × 停留估算。如设置起飞点，再加首尾水平往返距离 / 首点速度。没有建模完整起降爬升、曲线转弯、迎风、相机延迟或电池衰减。总览显示整体路线估算，ZIP 内每份清单可查看独立架次估算。

## 高度与动作

输出 `executeHeightMode = relativeToStartPoint`。不推算海拔，也不把相对高度当作 AGL。默认相对上限 120 m 是用户规划限制，不是实际真高或合规认定。

每点导出速度、机头角度和云台俯仰，动作组为抵达点后云台旋转及可选拍照。交界锚点也设置云台，但不拍照。未输出悬停时长动作，界面“停留估算”只计算时间。

完成任务设置 goHome，失联设置 executeLostAction/goBack。这是导出意图，需在当前 DJI Fly 版本和机型上检查最终解析设置。原系统的失联继续飞行默认值未被沿用。
