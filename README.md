# Mini Mission Planner

DJI Mini 5 Pro / Mini 4 Pro 的独立航线规划工作台。源于裂察者项目中的建筑巡检航线经验，重新实现为纯浏览器工具。

[English](README.en.md) · [兼容性说明](docs/COMPATIBILITY.md) · [DJI Fly 导入步骤](docs/DJI-FLY.md) · [算法与高度口径](docs/ALGORITHMS.md)

> **当前是 v0.1 技术预览。两款机型在这个独立版本中都尚未实飞验证。** Mini 5 Pro 的原系统有实飞经历，但不能代替本版本验证。Mini 4 Pro 配置来自社区参考。欢迎提供脱敏原生 KMZ、版本信息及试飞结果。

## 能做什么

- 区域测绘：绘制简单多边形，生成往返扫描线，支持凹多边形。
- 立面巡检：绘制开放折线，选择飞行侧、离墙距离及高度范围，多层往返。
- 环绕拍摄：设置中心、半径、圈数，机头朝向中心。
- Mini 4 Pro / Mini 5 Pro 参数选择，机型对应的云台俯仰校验。
- 相对高度、速度、坐标、自交边界和任务规模检查。
- 任务分段，导出一份 KMZ 或包含多份 KMZ 与估算清单的 ZIP。
- 项目 JSON 和 GeoJSON 导入，受限的 KMZ 航点导入，原生任务枚举校准。
- 中文 / English，浅色 / 深色按钮切换并记住选择。
- 坐标表键盘编辑。默认联网显示 OpenStreetMap，可关闭底图使用离线网格。
- 底图加载状态、网络失败提示、经纬度定位及自定义 XYZ 瓦片入口。
- 中英文地名搜索、候选结果选择及地图跳转，可更换查询服务。

不需要 MySQL、Java、显卡、地图密钥或 DJI 开发者账号。不是 DJI 官方产品，没有调用 DJI Fly 官方导入 API。

## 启动

安装 [Node.js](https://nodejs.org/) 22.12 以上版本，然后：

```sh
npm ci
npm run dev
```

打开终端显示的本机地址，默认 `http://127.0.0.1:5180`。Windows 也可双击 `start-local.bat`。首次安装依赖需要联网，依赖安装完成后关闭在线底图仍可规划。

```sh
npm run build           # 类型检查、生成 dist
npm run preview         # 预览生产构建
npm run check           # 核心测试和生产构建
npm run test:e2e        # 真实浏览器操作测试，先 npx playwright install chromium
npm run scan            # 公开文件模式扫描
```

使用已有 Chrome 验证：PowerShell 中设置 `$env:MMP_BROWSER='你的 Chrome 可执行文件绝对路径'`，再运行 `npm run test:e2e`。

## 快速使用

1. 选择机型和规划模式。在坐标表输入 WGS84 坐标，或导入 GeoJSON。点击地图添加点，拖拽点调整。
2. 设置高度、速度、重叠率、离墙距离及返航参数。所有高度都**相对起飞点**。
3. 在原生 DJI Fly 中创建短任务，从遥控器复制 KMZ，使用“导入原生 KMZ 校准枚举”。这只提取格式版本和机型枚举，不验证固件支持。
4. 检查航点表和提示。确认高度口径和兼容性边界后，导出 KMZ。
5. 按 [DJI Fly 导入步骤](docs/DJI-FLY.md) 在遥控器上替换占位任务。逐份检查航点、云台、拍照动作和返航设置，先做短距离试飞。

“演示数据”位于虚构场景原点附近，**不应用于实飞**。`examples/` 同样只用于学习和测试。

首次打开地图视角为中国北京，缩放等级 11，不自动载入演示航线。点击“演示数据”才生成示例并定位至示例区域。

地图上方可以搜索 `New York, USA` 或中文地名，选择结果跳转，已规划的航线保持原位。搜索文本会发给查询服务。默认服务仅用于当前本地预览，公共服务限制及公开部署要求见 [地名搜索说明](docs/PLACE-SEARCH.md)。

## 关键边界

- 网格是编辑辅助，不代表现场底图。OpenStreetMap 也不是飞行测量底图，需核验偏移及建筑轮廓。
- “底图与定位”可以查看现场经纬度，或应用有权访问的 HTTPS / 本机 HTTP XYZ 服务。必须使用与 WGS84 对齐的 Web Mercator 瓦片。GCJ-02、BD-09 不能直接混用。自定义地址只保留在当前页面，不写入项目文件，带密钥的地址不应提交 GitHub。
- 无三维网格或激光雷达碰撞检查。没有地形随动、GNSS 遮蔽、官方禁飞区或行政许可检查。
- 界面连线为直线示意。DJI Fly 的真实轨迹可能弯曲，扫描线连接段也可能离开多边形。
- 视场角按对角线和 4:3 成像推算，重叠率是几何估算，需根据真实照片校准。斜拍区域重叠不作保证。
- 12 m/s 是工具保守上限，不作为 Mini 5 Pro 官方航点速度规格。每份默认 99 个点，上限可调整至 200，但仍须按当前固件验证。
- 分段是独立架次，交界锚点不重复拍照。估算时长包含用户指定拍照停留及可选起飞点往返距离，但未加入所有爬升、转弯、风场和曲线轨迹耗时，不保证电池续航。
- KMZ 导入仅支持本工具使用的单航线、相对高度、显式机头角度、逐点云台和拍照模式。它是受限导入，不是任意 DJI 任务编辑器。
- 导入/导出文件在本机浏览器内处理，没有文件上传服务。开启在线底图会向 OpenStreetMap 发送地图视口相关请求。
